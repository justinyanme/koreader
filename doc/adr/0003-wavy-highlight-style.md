# 新增上游没有的“波浪线”划线样式

> 2026-10-23 起，这里的前提（微信读书有三种样式）和气泡里的样式行由 [ADR-0006](0006-straight-line-default-highlight.md) 取代：新划线默认直线，样式选择移到设置。波浪线样式本身保留，旧的波浪线划线照常显示，下文记下的代价仍然有效。

微信读书的划线有马克笔、直线、波浪线三种样式，而 KOReader 只有淡化、下划线、删除线、反色四种，没有波浪线。为了和微信读书保持一致，我们新增了一种波浪线样式。已知代价：这种样式记录在书的笔记文件（`.sdr`）里，用上游 KOReader 打开同一本书时，波浪线划线不会显示。这个 fork 只给自己用，这个代价可以接受。不要把它“修”回用删除线顶替。
